# LearnHub — Online Education Platform, Phase 1

This is the first working front-end prototype for the online education platform.

## Included
- Responsive professional homepage
- Course cards
- Tutor section
- Pricing section
- Login/sign-up modal
- Basic local browser account demo
- Mobile responsive layout

## Important
This is a front-end prototype. It is not yet connected to a production database, real authentication, payments, video hosting, or live classes.
